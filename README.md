## What EmberNet does for you

EmberNet is the operating system of the modern factory. It connects the equipment and edge hardware at your sites to one operations console, EmberCORE, without opening a single inbound port, and it deploys the industrial apps you run at the edge. Your people see every machine at every site, get the alert the moment something stops, and fix it without a truck roll.

It keeps working when the link to the cloud goes down.

## What you get

**One console for every site.** [EmberCORE](https://docs.embernet.ai/docs/dashboard/overview) shows your sites, devices, apps, network, storage, and alerts in a browser, with nothing to install.

**Security that does not depend on a perimeter.** [Flux](https://docs.embernet.ai/docs/services/flux) connects sites, devices, and cloud over outbound HTTPS on port 443. Access is granted between cryptographic identities, not network addresses, so there is no flat network for anyone to move across.

**An edge operating system that cannot drift.** [EmberRTOS](https://docs.embernet.ai/docs/emberrtos/overview) is immutable, updates as a whole, and rolls itself back if an update fails. Headless and Headless RT, for deterministic control loops, run on x86_64 and Raspberry Pi 4 and 5, and Desktop gives operator stations a local screen.

**Equipment read as it speaks.** Collectors read OPC UA, Modbus, S7comm, EtherNet/IP, MTConnect, FINS, MELSEC, BACnet/IP, and DNP3 directly. They only read, so monitoring never moves a machine.

**Apps that deploy in clicks.** The [App Store](https://docs.embernet.ai/docs/app-store/overview) puts CODESYS runtimes, Ignition, HotLoop, Node-RED, historians, rules engines, and monitoring on the node you choose, packaged and connected to the console.

**Many organizations, one platform.** Every tenant gets its own data, users, and roles, and the server enforces the separation on every request. Managed service providers and multi-division enterprises run on it without building their own isolation.

**Storage, messaging, and a workspace built in.** [Cinder](https://docs.embernet.ai/docs/services/cinder) keeps replicated volumes and backups, [AnvilMQ](https://docs.embernet.ai/docs/services/anvilmq) carries live data between devices and apps, and [Hearth](https://docs.embernet.ai/docs/hearth/overview) gives the team tasks, documents, a CRM, assets, and work orders.
